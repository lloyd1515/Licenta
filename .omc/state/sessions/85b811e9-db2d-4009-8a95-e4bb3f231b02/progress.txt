  ```python
  from scapy.utils import RawPcapReader, RawPcapWriter
  reader = RawPcapReader('ubertooth-standalone/data/captures/btle_ch37_20260617_085225.pcap')
  writer = RawPcapWriter('tests/fixtures/tiny_btle_sample.pcap', linktype=reader.linktype)
  writer._write_header(None)
  count = 0
  for pkt_data, pkt_metadata in reader:
      if count >= 50:
          break
      writer.write_packet(pkt_data, sec=pkt_metadata.sec, usec=pkt_metadata.usec,
                           caplen=pkt_metadata.caplen, wirelen=pkt_metadata.wirelen)
      count += 1
  writer.close(); reader.close()
  ```

estimate_position(corner_distances: dict, corner_coords: dict) -> tuple[float|None, float|None, str]:
- Functie pura: valid = intersectia cheilor prezente in ambele dict-uri cu distance is not None; nu muta corner_distances/corner_coords (verificat cu test dedicat, comparatie dict inainte/dupa apel).
- Precondiere Fable (Step 2 din plan): daca len(valid) < 3 -> (None, None, 'insufficient_corners'), formula NU se aplica deloc (nu doar "incredere redusa").
- Formula: weight_i = 1 / max(distance_i, EPSILON) cu EPSILON=0.1 (guard div-by-zero pentru distance_i=0), pozitie = suma ponderata / suma ponderilor, pe fiecare axa separat.
- Scheme confidence ales: string "{n_valid}/{n_total}" (ex. "4/4", "3/4") -- ales pentru ca reflecta EXACT notatia literala din tabelul de teste al planului (Axa 2: "confidence=4/4", "confidence=3/4 (medie)"), documentat in docstring.
