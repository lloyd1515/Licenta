dependencies sunt necesare la rulare. devDependencies sunt necesare doar la scrierea codului: tipurile TypeScript și compilatorul.

Ce înseamnă „^” din fața versiunii?

„^4.0.218” acceptă orice versiune 4.x mai nouă, dar nu 5.0. npm a ales efectiv 4.0.534, scrisă în package-lock.json.

De ce three și @types/three cu aceeași versiune?

Tipurile descriu funcțiile unei versiuni anume. O versiune diferită ar da erori false în editor.
