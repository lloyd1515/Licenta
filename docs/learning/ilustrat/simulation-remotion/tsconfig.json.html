Regulile verificatorului TypeScript

TypeScript verifică tipurile înainte de rulare. Acest fișier îi spune ce versiune de JavaScript să accepte, cum să citească JSX și cât de strict să fie. Remotion compilează singur codul, deci TypeScript doar verifică.

De ce noEmit?

Remotion are propriul bundler, care transformă TypeScript în JavaScript. TypeScript nu trebuie să scrie fișiere. El doar raportează erorile.

De ce strict?

Modul strict cere tipuri clare, de exemplu pentru TimelineState. O greșeală de nume în timeline.ts apare în editor, nu în videoclipul randat.
