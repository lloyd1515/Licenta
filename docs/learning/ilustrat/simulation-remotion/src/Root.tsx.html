Root.tsx declară o singură compoziție, numită MainScene. Compoziția spune ce componentă se desenează, câte cadre are videoclipul și ce mărime are imaginea.

FPS și TOTAL_FRAMES vin din timeline.ts. Astfel, durata videoclipului și durata actelor folosesc aceleași numere.

De ce id = MainScene?

Comanda build din package.json randează compoziția cu acest nume. Numele trebuie să fie identic în ambele locuri.
