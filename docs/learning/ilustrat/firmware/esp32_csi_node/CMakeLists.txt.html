De ce 3.16?

ESP-IDF 5.1, versiunea din sdkconfig, cere cel puțin această versiune de CMake. O valoare mai mică ar accepta un CMake care nu poate compila proiectul.

De ce o variabilă de mediu și nu o cale fixă?

Fiecare calculator instalează ESP-IDF în alt folder. Scriptul export.sh setează IDF_PATH. Astfel, același fișier merge pe orice calculator.

De ce ordinea include, apoi project?

Regulile ESP-IDF trebuie să existe înainte de comanda project. Ele schimbă felul în care project caută componentele.
