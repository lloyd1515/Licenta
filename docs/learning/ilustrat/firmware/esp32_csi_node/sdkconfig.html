Din ce este făcut fișierul

Atinge o zonă din bară.

Linia 2 spune „Automatically generated file. DO NOT EDIT.” Programul menuconfig scrie fișierul. Dacă îl editezi de mână, menuconfig poate suprascrie schimbarea.

De ce este în proiect, dacă este generat?

El fixează exact configurația folosită pentru capturi. Cineva care compilează din nou obține aceeași placă configurată.

Linia 1054 · CONFIG_FREERTOS_HZ

Ceasul care dă ritmul cadrelor trimise

Durata unui tick10 ms
Cadre de sondare, cel mult≈ 100 / s
Măsurat în capturi (nod 1)28–53 pachete / s

FreeRTOS împarte timpul în „tick-uri”. Funcția de sondare din main.c trimite un cadru, apoi așteaptă un tick. Deci ritmul maxim de cadre este aproximativ egal cu frecvența ceasului.

Diferență față de README

README spune că nodul emite la 250 Hz. Cu această setare, pauza este de 10 ms. Ritmul maxim este deci aproximativ 100 de cadre pe secundă. Capturile reale au între 28 și 53 de pachete pe secundă.
