Componenta „main”

ESP-IDF împarte firmware-ul în componente. Acest fișier declară componenta main: ea are un singur fișier sursă, main.c.

Liniile 1–2 · înregistrarea componentei

Un fișier sursă, multe biblioteci gata făcute

Atinge o componentă.

Linia 1 înregistrează componenta și lista ei de surse: doar main.c. Linia 2 spune unde sunt fișierele antet ale componentei: în același folder.

Componenta main are o regulă specială în ESP-IDF. Ea poate folosi toate celelalte componente fără o listă de dependențe.

De ce nu apare o listă de dependențe?

Pentru main, ESP-IDF adaugă automat toate componentele. Pentru un proiect mic, cu un singur fișier, regula simplifică configurarea.

De ce folderul „.”?

main.c nu are fișiere antet proprii. Valoarea „.” este cea mai simplă alegere validă.
