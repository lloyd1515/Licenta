Fișierul nu conține nimic. Prezența lui spune lui Python că folderul csi este un pachet. Astfel, celelalte fișiere scriu „csi.room” sau „csi.dsp” când importă ceva.

Folderul devine pachet

Python caută modulele în foldere. Un folder cu acest fișier este un „pachet obișnuit”. Numele pachetului este numele folderului: csi.

Fiecare import din proiect începe cu acest nume. De exemplu, dsp.py cere funcția de detecție din csi.fall_detector.

De ce un fișier gol și nu niciun fișier?

Python 3 găsește folderul și fără acest fișier, ca „pachet namespace”. Fișierul gol face intenția clară. Unelte ca pytest recunosc pachetul imediat.

De ce nu are cod?

Codul din acest fișier rulează la primul import al pachetului. Proiectul nu are nevoie de nimic la acel moment. Un fișier gol nu încetinește pornirea.
