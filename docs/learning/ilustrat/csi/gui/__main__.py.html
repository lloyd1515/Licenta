Alege o comandă și vezi ce face

--replay are „nargs='?'”: valoarea este opțională. Fără opțiune, valoarea este None. Cu opțiunea, dar fără cale, valoarea este „DEFAULT”. Cu o cale, valoarea este calea.

De ce trei stări pentru o opțiune?

O singură opțiune acoperă trei cazuri: fără replay, replay cu fișierul implicit (test C) și replay cu alt fișier.

Liniile 48–70 · main

Pornirea, în ordine

Linia 50 lasă Ctrl+C să închidă programul direct. Liniile 56–59 pornesc un temporizator care nu face nimic la fiecare 200 ms. sys.exit(app.exec()) rulează bucla Qt și întoarce codul ei de ieșire.

De ce un temporizator care nu face nimic?

Cât timp rulează bucla Qt, codul C++ al Qt are controlul. Python vede Ctrl+C doar când rulează cod Python. Temporizatorul dă controlul lui Python de 5 ori pe secundă.
