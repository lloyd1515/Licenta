Harta amplitudinii pe subpurtătoare

Zece rânduri goale

Rândurile 21–30 sunt aproape 0 în toate cele trei capturi. dsp.py le elimină, pentru că varianța lor este sub 0.05. Pagina packets.py explică o cauză probabilă.

Fiecare coloană de pixeli este un moment. Fiecare rând este o subpurtătoare, de jos (0) în sus (51). Culoarea arată amplitudinea: albastru închis = mică, galben = mare.

Rândurile 21–30 sunt mereu închise: amplitudinea lor este aproape 0. Restul hărții variază fără un model clar. Aceasta este variația de fond a canalului.
